## 2. Automatic Custom Module Creation (Zoho API v8)

When the widget opens, it executes an automatic verification handshake. If the custom modules are not yet in your CRM organization, the widget automatically creates them using the Zoho CRM v8 API:

### API Request Generated by Widget:
```http
POST https://www.zohoapis.com/crm/v8/settings/modules
Content-Type: application/json
Authorization: Zoho-oauthtoken <ACCESS_TOKEN>

{
  "modules": [
    {
      "api_name": "Living_Docs_Snapshots",
      "singular_label": "Living Docs Snapshot",
      "plural_label": "Living Docs Snapshots"
    },
    {
      "api_name": "Doc_Drift_Logs",
      "singular_label": "Doc Drift Log",
      "plural_label": "Doc Drift Logs"
    }
  ]
}
```

### Auto-Configured Fields on `Living_Docs_Snapshots`:
- `Name`: Snapshot Identifier (e.g. `Snapshot_20260929_1530`)
- `Snapshot_JSON`: Normalized metadata JSON
- `Component_Hashes`: Cryptographic hash map per component
- `Status`: Picklist (`Active Baseline`, `Archived`, `Draft`)
- `Generated_Markdown`: Living Markdown documentation
- `WorkDrive_File_URL`: Export link to WorkDrive

*(The widget displays `⚡ Custom Module Auto-Provisioned` in the header bar upon successful handshake).*

## 3. Zoho CRM Widget Installation

### Option A: Local Testing with ZET (Zoho Extension Toolkit)
1. Start the widget server:
   ```bash
   npm start
   ```
2. Open `https://127.0.0.1:5000/app/widget.html` in your browser and authorize the self-signed SSL certificate (Advanced -> Proceed).
3. In Zoho CRM, navigate to **Setup (Gear icon) -> Developer Space -> Widgets -> Create New Widget**:
   - **Widget Name**: `Living Documentation Agent`
   - **Widget Type**: `CRM`
   - **Hosting**: `External`
   - **URL**: `https://127.0.0.1:5000/app/widget.html`
4. Assign the widget to a **Web Tab** (Settings -> Customization -> Modules and Fields -> Web Tabs -> Add Web Tab -> Select Widget).

### Option B: Packaged Zip Upload
1. Package the `app/` folder and `plugin-manifest.json` into a `.zip` file.
2. In Zoho CRM **Widgets** -> Select **Internal / Zoho Hosting** -> Upload zip file.
